# Tata Power EV Charging Infrastructure Analysis

## Project Overview

Developed an interactive Excel dashboard to analyze EV charging infrastructure performance, customer demand, station utilization, financial performance, and expansion opportunities across districts.

## Objectives

- Analyze charging demand and usage trends over time
- Evaluate station utilization and operational efficiency
- Understand customer charging behavior and usage patterns
- Assess financial performance and project profitability
- Identify high-potential locations for future expansion

## Tools & Skills

- Microsoft Excel
- Data Cleaning & Transformation
- Data Analysis
- Dashboard Development
- PivotTables & PivotCharts
- KPI Analysis
- Data Visualization
- Financial & ROI Analysis

## Key Analysis

- Analyzed total charging sessions, energy consumption, revenue, active customers, and average session metrics.
- Evaluated station utilization using sessions per station, sessions per plug, plug capacity, and district-wise station density.
- Segmented customer behavior by income tier, EV model, and battery capacity.
- Evaluated CAPEX, annual revenue, EBITDA, payback period, subsidy impact, and 5-year ROI.
- Identified demand-supply gaps by comparing projected EV demand with available charging infrastructure.
- Classified districts based on demand, utilization, and ROI to support expansion prioritization.
